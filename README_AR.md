# متجر القاسمية عبر تيليجرام — النسخة الأولية

هذه نسخة أولية قابلة للتشغيل والاختبار. تشمل:
- بوت تيليجرام يستقبل `/start` ويعرض زر فتح المتجر.
- واجهة متجر عربية (Telegram Mini App) تعرض المنتجات وتدير السلة.
- تسجيل الطلبات وخصم المخزون.
- لوحة إدارة محمية باسم مستخدم وكلمة مرور.
- إدارة المنتجات والطلبات وحالاتها.
- الدفع عند الاستلام، وخيار رابط دفع إلكتروني خارجي عند ضبط `PAYMENT_URL`.

## 1) ما تحتاجه
- حاسوب (Windows / macOS / Linux).
- Python 3.11 أو أحدث.
- حساب تيليجرام.
- بوت أنشأته من [@BotFather](https://t.me/BotFather).
- استضافة تدعم HTTPS قبل فتح المتجر للزبائن.

## 2) التشغيل المحلي للتجربة
افتح مجلد المشروع في Terminal / PowerShell ثم:

### Windows
```powershell
py -m venv .venv
.venv\\Scripts\\activate
pip install -r requirements.txt
copy .env.example .env
```

### macOS / Linux
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

عدّل ملف `.env`:
- ضع `BOT_TOKEN` الذي حصلت عليه من BotFather.
- ضع `ADMIN_USERNAME` و`ADMIN_PASSWORD` قويين.
- اترك `DEV_MODE=true` للاختبار المحلي فقط.
- `WEBAPP_URL` لا يعمل كرابط تيليجرام إلا بعد نشر الموقع على HTTPS.

شغّل:
```bash
uvicorn app.main:app --host 127.0.0.1 --port 8000
```
ثم افتح:
- المتجر التجريبي: http://127.0.0.1:8000
- لوحة الإدارة: http://127.0.0.1:8000/admin

بيانات الدخول هي التي وضعتها في `.env`. ستظهر نافذة تطلب اسم المستخدم وكلمة المرور.

## 3) ربط البوت
بعد نشر التطبيق على عنوان HTTPS:
1. ضع الرابط العام في `WEBAPP_URL`.
2. ضع رمز البوت في `BOT_TOKEN`.
3. أضف `ADMIN_CHAT_ID` إلى `.env` (معرّف محادثتك الرقمية) لتصلك تنبيهات الطلبات.
4. غيّر `DEV_MODE=false`.
5. أعد تشغيل الخدمة.
6. افتح البوت واضغط Start، ثم زر «افتح المتجر».

للحصول على `ADMIN_CHAT_ID`، يمكنك استخدام بوت موثوق لعرض معرّف حسابك أو إضافة خطوة إعداد آمنة. لا ترسل رمز البوت لأي جهة.

## 4) إدخال المنتجات
افتح `/admin`، ثم تبويب «المنتجات»، وأضف:
- الاسم والفئة
- السعر بالدينار
- المخزون
- الألوان والمقاسات مفصولة بفواصل
- رابط صورة HTTPS
- الوصف

المنتجان الأوليان أمثلة فقط بسعر ومخزون صفر؛ لا يمكن طلبهما حتى تضيف السعر والمخزون.

## 5) الدفع الإلكتروني
النسخة الأولية لا تجمع بيانات البطاقات ولا تنفذ خصماً بنفسها. بعد التعاقد مع مزود دفع يدعم نشاطك في الجزائر:
- ضع رابط الدفع الآمن الخاص بمزودك في `PAYMENT_URL`.
- اختبر عملية الدفع والتأكيد مع المزود.
- لا تعتبر الطلب مدفوعاً لمجرد فتح الرابط؛ يلزم لاحقاً ربط إشعار تحقق (webhook) من مزود الدفع لتأكيد حالة الدفع.

## 6) قبل الإطلاق العام — مهم
هذه نسخة MVP تعليمية وليست جاهزة لاستقبال الجمهور كما هي. قبل الإطلاق:
- استخدم HTTPS واستضافة دائمة.
- اجعل `DEV_MODE=false`.
- غيّر كلمات المرور والأسرار الافتراضية.
- استخدم PostgreSQL بدلاً من SQLite عند التوسع.
- أضف تحديد معدل الطلبات، حماية CSRF المناسبة، وسجل تدقيق.
- أضف إدارة صور آمنة ورفع ملفات بدلاً من روابط غير موثوقة.
- أضف رسوم التوصيل حسب الولاية.
- أضف مخزوناً مستقلاً لكل لون ومقاس، بدلاً من المخزون الإجمالي الحالي.
- اربط بوابة الدفع عبر API وwebhook موثق.
- اختبر الخصم المتزامن للمخزون، الإلغاء، والاسترجاع.

## 7) الدعم
ابدأ بالتجربة محلياً بمنتجات وأسعار تجريبية. لا تنشر رابط المتجر للزبائن قبل إتمام قائمة ما قبل الإطلاق.
